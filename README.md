# Kata Cinema Banboger Backend Application

This repository contains the source code for a Cinema Management Backend Application. The application allows users to manage movies services, rooms services, email services and reservations services. It is built using Java and SpringBoot.

## Installation

To install and run this application locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/SantiagoOrtega/kata-cinema-mngr.git
   cd kata-cinema-mngr
   ```

2. Install the dependencies:
   ```bash
   mvn clean install
   ```

3. Start the development server:
   ```bash
   mvn spring-boot:run
   ```

4. Manage this application with `http://localhost:8080`.
